# PAI-001 — Acta de Inicio del Proyecto



**Proyecto:** PAI Digital — Sistema de Gestión del Plan de Acción Institucional  

**Institución:** Fundación Universitaria María Cano  

**Versión:** 0.1 — Borrador  

**Fecha:** 13 de octubre de 2026  

**Estado:** Pendiente de revisión y aprobación funcional



## 1. Antecedentes



Actualmente, la gestión del Plan de Acción Institucional (PAI) se realiza mediante un instrumento de Excel que consolida la planeación, las metas, las actividades, los indicadores y el seguimiento de las diferentes dependencias institucionales.



El proceso comprende la formulación de la planeación, el reporte periódico de avances y la presentación de evidencias para su revisión.



Se identifica la oportunidad de implementar una solución web centralizada que facilite la administración de la información, reduzca la intervención manual y mejore la trazabilidad de los reportes y sus validaciones.



## 2. Justificación



El proyecto PAI Digital busca modernizar la gestión del Plan de Acción Institucional mediante una aplicación web integrada con los servicios tecnológicos de Microsoft 365.



La solución permitirá organizar la planeación, realizar seguimiento trimestral, centralizar evidencias y proporcionar información para la toma de decisiones.



## 3. Objetivo general



Desarrollar e implementar una aplicación web institucional para administrar, registrar, validar y consultar la planeación y los avances del Plan de Acción Institucional de la Fundación Universitaria María Cano.



## 4. Objetivos específicos



\- Centralizar la información de líneas estratégicas, dependencias, metas, actividades e indicadores.

\- Facilitar el registro de avances trimestrales por parte de los responsables.

\- Implementar mecanismos de revisión, aprobación y devolución de reportes.

\- Centralizar la gestión de evidencias documentales.

\- Proporcionar indicadores y tableros de seguimiento.

\- Garantizar controles de acceso y trazabilidad de las operaciones.



## 5. Alcance preliminar



La solución contemplará los siguientes módulos:



1\. Inicio y resumen institucional.

2\. Gestión del PAI.

3\. Reporte trimestral.

4\. Validación de avances.

5\. Gestión de evidencias.

6\. Dashboard e indicadores.

7\. Auditoría y seguimiento de cambios.



El alcance funcional definitivo se establecerá durante el levantamiento y validación de requisitos con Planeación.

## 7. Arquitectura tecnológica preliminar



\- **Frontend:** React y TypeScript.

\- **Herramienta de desarrollo:** Vite.

\- **Control de versiones:** Git y GitHub.

\- **Alojamiento:** Azure Static Web Apps.

\- **Autenticación:** Microsoft Entra ID.

\- **Integración:** Microsoft Graph.

\- **Persistencia:** SharePoint Lists.

\- **Documentos:** bibliotecas de SharePoint.

\- **Automatización:** Power Automate para procesos programados y notificaciones, cuando corresponda.



La arquitectura está sujeta a validaciones técnicas, de seguridad, rendimiento y licenciamiento.
